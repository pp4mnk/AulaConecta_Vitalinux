# AulaConecta_Vitalinux

Aula Conecta  · pp4mnk, con instalador .deb, código e instrucciones.

Un primer intento de solucionar los problemas tan frecuentes de conexión en los colegios con vitalinux.

Aula-Conecta-0.1.0-pp4mnk.zip

Que incluye este software:
- Detección automática de pantallas, táctiles y salidas de sonido.
- Botones para activar, duplicar o ampliar la imagen en un click.
- Restauración automática en 20 secs si no confirmas el cambio de vídeo.
- Asociación del táctil a la pantalla seleccionada.
- Alguna cosilla más para informar al soporte
  
Para instalarlo: extrae el ZIP, abre una terminal en la carpeta extraída y ejecuta:
sudo apt install ./aula-conecta_0.1.0_all.deb o simplemente, tras descomprimir ejecuta el instalador, que tiene permisos concedidos para root, user....bla,bla,bla.

Después abre Aula Conecta desde el menú de aplicaciones.

Es una primera versión para Vitalinux con X11 y Python 3.8 o superior. Necesita ser probada en un equipo Vitalinux real con un maestro tipo, que no sea un hacker informático, para ver que sería necesario implementar o si da errores.
Por supuesto, obviamente, no puedo garantizar todos los modelos ni solucionar mediante software cables o adaptadores que falten. Si ya no se arregla, informar a mantenimiento  (o al COFOTAP).
